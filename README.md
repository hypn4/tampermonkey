# Tampermonkey Userscripts

브라우저 사용 편의성을 높이는 Tampermonkey 유저스크립트 모음입니다.

## 스크립트 목록

| 스크립트 | 버전 | 설명 | 설치 |
| :--- | :---: | :--- | :---: |
| 치지직 광고 차단 감지 우회 | `v0.3.0` | 광고 차단 감지로 인한 재생 중단·화질 저하 방지 | [설치](https://raw.githubusercontent.com/hypn4/tampermonkey/main/chzzk-adblock-detect-bypass.user.js) |
| 치지직 라이브 자동 최고화질 | `v0.1.0` | 라이브 화질을 최고 해상도로 고정 | [설치](https://raw.githubusercontent.com/hypn4/tampermonkey/main/chzzk-auto-highest-quality.user.js) |
| 치지직 그리드 없는 고화질 | `v0.2.0` | 그리드 설치 없이 고화질 수동 선택 | [설치](https://raw.githubusercontent.com/hypn4/tampermonkey/main/chzzk-no-grid.user.js) |
| 치지직 통나무 파워 자동 획득 | `v0.1.0` | 통나무 파워 자동 획득 및 팝업 배너 닫기 | [설치](https://raw.githubusercontent.com/hypn4/tampermonkey/main/chzzk-auto-log-power.user.js) |

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 확장 프로그램을 설치합니다.
2. 위 목록에서 원하는 스크립트의 **설치** 링크를 열고 설치를 승인합니다.
3. 스크립트가 활성화되어 있는지 확인한 뒤 대상 웹사이트를 새로고침합니다.

대상 웹사이트의 변경이나 다른 확장 프로그램과의 충돌로 스크립트가 동작하지 않을 수 있습니다.

## 자동 업데이트 안내

스크립트에 지정된 업데이트 URL을 통해 Tampermonkey가 자동 업데이트합니다. 수동 확인은 대시보드의 **지금 업데이트 확인**을 사용합니다.
